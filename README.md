
# 📝 Formulário de Cadastro

Formulário de cadastro de usuários desenvolvido com HTML e estilizado com CSS, com foco em usabilidade e validação de campos.

---



## ✨ Funcionalidades

- 👤 Campos de dados pessoais (nome, e-mail, senha)
- ✅ Estrutura pronta para validação
- 📱 Layout responsivo

---

## 🛠️ Tecnologias utilizadas

| Tecnologia | Uso |
|---|---|
| HTML5 | Estrutura do formulário e campos |
| CSS3 | Estilização e layout |

---

## ▶️ Como rodar o projeto

```bash
# 1. Clone o repositório
git clone https://github.com/brunoluiz131094/formulario_cadastro.git

# 2. Acesse a pasta
cd formulario_cadastro

# 3. Abra o index.html no navegador
```

---

## 📚 O que aprendi neste projeto

- Criação de formulários acessíveis com HTML semântico
- Tipos de inputs e atributos de validação nativa
- Estilização de formulários com CSS
